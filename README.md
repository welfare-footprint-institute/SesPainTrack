# Pain Track SES templates

This public repository is the canonical Welfare Footprint Institute copy of the retained Pain Track AWS SES template source.

## Current status

Pain Track is intentionally paused. This repository preserves template history and expected message shapes; it does not prove that WFI controls or uses the historical AWS account, SES identities, templates, or access keys.

- No automated deployment is configured by this repository transfer.
- Transactional-email replacement or reactivation is deferred.
- Running a template update script writes to AWS and requires separate approval, verified institutional provider ownership, and appropriately scoped credentials.
- Do not commit credentials or local environment files.

Canonical public system documentation: [`welfare-footprint-institute/pain-track-docs`](https://github.com/welfare-footprint-institute/pain-track-docs)

The technical role and retained template inventory are documented in [`aws_ses.md`](https://github.com/welfare-footprint-institute/pain-track-docs/blob/main/aws_ses.md).
